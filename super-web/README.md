# Super Web

A modern React application for interacting with and visualizing the Super Powers universe. Built with **Vite**.

## Features
*   **Tech Stack:** React 19, Vite, Axios.
*   **Styling:** Custom CSS with a focus on immersive aesthetics (Glassmorphism, Dynamic Backgrounds).
*   **Integration:** Designed to consume APIs from `super-services` (future integration).

## Setup & Run

### 1. Install Dependencies
```bash
cd super-web
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
The app will be available at `http://localhost:5173`.

## Structure
*   `src/`: Components and assets.
*   `index.css`: Global styles and theming.
